# Jira: Dashboards and Reports

A **dashboard** is a page that collects several views of project data in one place, such as filter results, charts, and progress gadgets. A **report** is a specific chart or summary that shows how work is moving over time. Dashboards help people check the state of work at a glance, and reports help teams understand how well they are working.

## Dashboards

A dashboard is built from **gadgets**, which are small panels that each show one piece of information. Common gadgets display:

- **Filter results:** a list of issues matching a saved filter, such as "open bugs."
- **Statistics:** counts of issues grouped by status, assignee, or priority.
- **Charts:** a visual of data over time or across categories.
- **Sprint or project progress:** how much of the current work is complete.

Dashboards can be personal or shared. A shared dashboard works well for a team meeting or a stakeholder update, because everyone sees the same numbers.

## Reports

Jira Software includes built-in reports for agile teams. The most common are:

- **Burndown chart:** shows the remaining work in a sprint over time, compared with an ideal line. It shows whether the team is on track.
- **Velocity chart:** shows how much work the team completed in past sprints. It helps estimate how much to plan next time.
- **Cumulative flow diagram:** shows how many issues sit in each status over time. Widening bands suggest a bottleneck.
- **Control chart:** shows how long issues take to finish. It helps spot unusual delays.

Each report answers a different question. Burndown asks whether the sprint will finish, velocity asks how much the team can take on, and the flow diagram asks where work is getting stuck.

## Reading Reports Carefully

Reports reflect the data in Jira, so their accuracy depends on how consistently the team updates issues, estimates, and statuses. A chart showing an unusual drop is a prompt to ask what changed, not proof of a problem by itself. Reports work best as a starting point for conversation.

## Key Idea

Dashboards show the current state of work, and reports show how that work has moved over time. Both are only as useful as the discipline behind the issues they are built from.
